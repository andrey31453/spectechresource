## 1. Цель, KPI, модель продукта

- **Бизнес-цель:** заявки и звонки от юрлиц с поиска и Яндекс.Директа.
- **Целевые действия (в порядке ценности):** отправка формы → звонок → клик в мессенджер.
- **Модель продукта:** SSR-сайт-витрина (каталог + ~39 SEO-лендингов). Без онлайн-оплаты, без ЛК клиента, без корзины.
- **KPI для приёмки (согласовать с заказчиком):** PageSpeed mobile ≥ 70 (P0), все формы доходят до Битрикс24 (P0), цели Метрики фиксируют формы/звонки/мессенджеры (P0).
- **Коммерческие KPI (вне зоны ответственности разработки):** лиды/мес, CPL, конверсия лендинга — задаются рекламой и контентом.

## 2. Аудитория и конверсионные сценарии

- **Кто:** строительные, подрядные, коммунальные организации (B2B), ЛПР — прораб, снабженец, директор.
- **Запрос:** «аренда + вид техники + город»; решение принимается по наличию техники, цене за смену, сроку подачи.
- **Сценарий A (поиск):** лендинг вида техники → цена «от» + условия → форма/звонок.
- **Сценарий B (Директ):** объявление → лендинг → блок «цена и условия» → форма (UTM обязательны).
- **Сценарий C (не нашёл):** блок/страница «Не нашли технику?» → форма подбора.
- **Сценарий D (мобайл):** кликабельный телефон и мессенджеры в первом экране и в «липкой» панели.

## 3. Границы проекта

**В скоупе (по ТЗ):** главная, каталог из 6 разделов / 39 позиций, шаблон посадочной страницы, услуги (опционально), контакты, политика ПДн, формы → Битрикс24, Метрика, SEO-обвязка (мета, sitemap, robots, микроразметка, крошки, ЧПУ), адаптив, WebP, админка для каталога, домен/хостинг/SSL, регистрация в Вебмастере и Бизнесе.

**Вне скоупа (по умолчанию; подтвердить, Q-13):** личный кабинет, онлайн-оплата и счета, интеграция с 1С, блог/новости, мультиязычность, e-mail/Telegram-рассылки, мобильное приложение, автоматический расчёт доставки по адресу, онлайн-чат оператора (только мессенджеры).

## 7. Страницы и блоки

### STR-01 (P0) Главная — жёсткий порядок блоков
1. **Шапка:** логотип, меню, телефон (кликабельный), режим работы, кнопка «Заказать технику».
2. **Первый экран:** H1, регион работы, форма расчёта (имя, телефон, вид техники), 3 цифры — парк / срок подачи / лет на рынке.
3. **Каталог** «Спецтехника в аренду» по разделам (CAT-01) + дисклеймер (CAT-02).
4. **Услуги.**
5. **Преимущества.**
6. **Порядок работы** — 4 шага.
7. **CTA «Не нашли технику?»** → форма.
8. **FAQ** — аккордеон, разметка FAQPage.
9. **Контакты + подвал:** телефон, e-mail, мессенджеры, адрес, реквизиты, политика ПДн, счётчики.

*Критерий:* на ширине 360–375 px — одна колонка, телефон и кнопка заявки доступны без горизонтального скролла.

### STR-02 (P0) Страница раздела (6 шт.)
Крошки → H1 → краткое описание → сетка карточек позиций (название, «от N руб/смена», фото, ссылка)
→ SEO-текст → перелинковка на смежные разделы → CTA-форма.

### STR-03 (P0) Посадочная страница вида техники — шаблон, 39 стр.
| Блок | Требование |
|---|---|
| H1 | «Аренда {вид техники} в {город}» — из `nameGenitive` + город |
| Цена и условия | «от N руб/смена», минимальный заказ, доставка (условия и стоимость), с экипажем / без |
| Таблица моделей | марка/модель, ключевые характеристики, цена за смену / за час |
| Фото техники | галерея, WebP/AVIF, `alt` с названием техники |
| «Какие работы выполняет» | `worksPerformed` |
| Форма заявки + звонок + мессенджеры | Telegram, WhatsApp, MAX (FRM-01…03) |
| FAQ по виду техники | 3–6 вопросов, разметка FAQPage |
| SEO-текст | текстовый блок 1500–3000 знаков, редактируемый |
| «Похожая техника» | 3–4 позиции из раздела (перелинковка) |
| Крошки | Главная / Каталог / Раздел / Вид |

### STR-04 (P0) Сквозные элементы
Крошки с BreadcrumbList, «липкая» мобильная панель (позвонить / заявка), кнопка «наверх» (P2),
cookie-уведомление при наличии аналитических cookie (P2).

### STR-05 (P1) Услуги — 5 позиций (земляные работы, вывоз грунта, демонтаж, планировка, перевозка тралом).
Включаются только по решению заказчика (Q-04).

### STR-06 (P0) Контакты
Телефон, e-mail, мессенджеры (Telegram, WhatsApp, MAX), адрес, реквизиты (наименование, ИНН, ОГРН),
карта (ленивая загрузка iframe, без блокировки рендера), форма заявки.

### STR-07 (P0) Политика обработки ПДн
Отдельная страница `Page` + текст согласия в каждой форме (чекбокс, обязательный, ссылка на политику).

### STR-08 (P1) 404 / 500
Страница в шаблоне сайта, ссылки на каталог и контакты, корректный HTTP-код.
