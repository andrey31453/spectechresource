# Каталоги категорий — 27.11.2026

`/arenda-{categorySlug}` показывает общий компонент каталога с видами и
опубликованными моделями только опубликованной категории.
`GET /api/catalog/models?categorySlug=…` ограничивает выборку на сервере;
без параметра возвращается весь каталог. «Вся техника» сбрасывает только фильтр вида.

`GET /api/rental-route?slug=…` определяет категорию или вид. При коллизии
приоритет у опубликованного вида, чтобы сохранить существующий URL. Неизвестный
или неопубликованный адрес возвращает 404. Страницы моделей не меняются.

Общий `CatalogListing` используется на `/katalog` и страницах категорий.
Карточки сохраняют карусель, марку/модель и цены. Описание, характеристики,
подзаголовок вида и кнопка подробностей удалены только из карточек списка.
Фото и текст ведут на модель; стрелки — отдельные кнопки вне ссылок.
Марка, модель, H1 товаров и подробные характеристики товара не меняются.

Приёмка: категории не содержат чужих видов/моделей; фильтр и сброс работают;
виды и модели доступны по прежним адресам; карусель не вызывает переход;
проверки lint/test/typecheck/build и аудит 375/768/1280.
