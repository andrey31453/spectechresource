# Спека слайса `admin-pages` — статические страницы

| | |
|---|---|
| Статус | ✅ реализовано и проверено 16.11.2026 (dev `:3999`, 243 unit-теста) |
| Слайс | админ-API страниц (`pages`) и экраны `/admin/pages`, `/admin/pages/new`, `/admin/pages/[id]` |
| Не входит | WYSIWYG, история версий, планирование публикации, переводы, ALT для картинок |

## Зачем

Политика ПДн и другие статические страницы (`Page`) меняются только сидом или Prisma Studio.
Публичный `/api/pages/{slug}` и `sitemap.xml` читают PostgreSQL на каждый запрос, кэша нет —
после сохранения изменения видны сразу. SEO-тексты разделов и видов уже редактируются
в `admin-catalog`, здесь остаются только корневые страницы.

## Контракт API

Все хэндлеры под `/api/admin/**`: middleware проверяет сессию и CSRF, в каждом хэндлере —
`requireAdmin(event)` (ADR-19, ADR-20). Ошибки — в общем формате
`{ message, data: { errors: [{ field, message }] } }`.

| Метод и путь | Назначение | Успех |
|---|---|---|
| `GET /api/admin/pages` | список без контента, свежие правки сверху | `{ pages }` |
| `GET /api/admin/pages/:id` | карточка: контент, SEO, даты | `{ page }` |
| `POST /api/admin/pages` | новая страница | `201 { page }` |
| `PATCH /api/admin/pages/:id` | правка только переданных полей | `{ page }` |
| `DELETE /api/admin/pages/:id` | удаление и чистка редиректов на её адрес | `{ ok: true }` |

Коды ошибок: `400` — схема не прошла (поля с русскими текстами), `401` — нет сессии,
`404` — страницы нет, `409` — занятый `slug` (`P2002`).

## Валидация (`shared/schemas/admin-pages.ts`)

Схемы общие для формы и сервера; форма шлёт строки, сервер приводит их к виду Prisma.
`slug`, `requiredText`, `optionalText` переиспользуются из `shared/schemas/catalog.ts`.

| Поле | Правило |
|---|---|
| `slug` | правила каталога (2–80, латиница в нижнем регистре, цифры, дефис) |
| `slug`, занятые сайтом | запрещены `admin`, `api`, `uploads`, `katalog`, `uslugi`, `kontakty`, `_nuxt` и префикс `arenda-` |
| `title` | обязательный текст, 2–200 символов |
| `content` | markdown, обязательный, 1–100 000 символов, обрезается по краям |
| `seoTitle` | необязательный, до 200 символов, пусто → `null` |
| `seoDescription` | необязательный, до 300 символов, пусто → `null` |
| `isPublished` | boolean; при создании `true` |
| `PATCH` | `partial`-схема: отсутствующие поля остаются `undefined`, Prisma их не трогает |

Зарезервированные коды отклоняются схемой, а не проверкой в хэндлере: страница с адресом
`/katalog` никогда не откроется — её перекрывает настоящий раздел каталога, и администратор
должен увидеть ошибку у поля, а не пустую страницу на сайте.

## Адреса и редиректы (ADR-6)

- Страница живёт в корне: `/{slug}` (`app/pages/[slug].vue`).
- Смена кода: старый адрес получает `301` на новый — запись в `Redirect` (`upsert` по `from`),
  кэш таблицы сбрасывается сразу (`invalidateRedirectCache`).
- Удаление страницы удаляет редиректы с `to = /{slug}`: иначе старые ссылки уходили бы
  `301` в пустоту вместо честного `404`.

## Экраны

| Путь | Что |
|---|---|
| `/admin/pages` | таблица: страница и `/код`, публикация, дата обновления, действия |
| `/admin/pages/new` | пустая форма; после создания — переход в редактор созданной страницы |
| `/admin/pages/[id]` | редактор: markdown-текст, SEO-поля, публикация, удаление, «открыть на сайте» |

Форма одна на создание и правку (`app/components/admin/AdminPageForm.vue`), поэтому поля
и обработка ошибок не расходятся. Ссылки добавлены в навигацию админки и на дашборд,
`/admin/pages` открывается в широкой колонке.

## Проверено 16.11.2026 (dev на `:3999`)

- Без cookie `GET /api/admin/pages` → `401`; `/admin/pages` → `302` на вход с `next`.
- `POST` с кодом `katalog` → `400`, ошибка по полю `slug` («Этот адрес занят разделом сайта»).
- `POST` тестовой страницы → `201`; публичный `/api/pages/test-stranica` отдаёт
  `contentHtml` с `<h2>` и `<p>`.
- `PATCH` со сменой кода → `200`; `/test-stranica` → `301` на `/test-stranica-new`;
  API нового адреса → `200`.
- Повторный `POST` с занятым кодом (код политики ПДн) → `409` («Страница с таким кодом уже есть»).
- `DELETE` → `200`; `/api/pages/test-stranica-new` → `404`, старый `/test-stranica` → `404`
  (редирект удалён), в списке осталась только страница политики.
- `/admin/pages`, `/admin/pages/new` и `/admin/pages/{id}` с cookie → `200`, форма рендерит
  `textarea.field__textarea--code`; без cookie — `302`.
- `npm run lint` — чисто; `npm test` — 243/243; `npm run typecheck`; `npm run build` — успешно.

## Ограничения (осознанные)

- Markdown рендерит мини-парсер `server/utils/markdown.ts`: заголовки `#`/`##`/`###`, списки,
  цитаты, `**жирный**`, `_курсив_`, ссылки. Таблиц, картинок и вложенных списков нет —
  полноценный редактор или `marked` не подключались (AGENTS §3, нужна зависимость).
- Предпросмотра нет: текст проверяется на сайте после сохранения.
- Истории версий нет: сохранение перезаписывает страницу, параллельная правка двух
  администраторов оставит последнюю.
- Отложенной публикации нет — только флаг `isPublished`.
- Удаление необратимо (подтверждение в браузере), корзины нет.
