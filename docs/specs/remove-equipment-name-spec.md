# Удаление дублирующей характеристики названия

Согласовано: удалить «Название техники» из `equipment_specs`, а не только скрыть.
Основное название остаётся в `EquipmentModel.brand` / `model`; заголовок страницы
собирается из названия вида, марки и модели. Эти поля и URL не изменяются.

Миграция `20261127140000_remove_equipment_name_spec` удаляет только строки с этим
названием (без учёта регистра, лишних пробелов, NBSP и завершающего двоеточия).
Перед локальным применением сохраняется резервная копия БД.

Импорт с сайтов, загрузка старых архивов и объединение дублей исключают эту
характеристику. Остальные характеристики сохраняются; исходные архивы не меняются.
Ручное добавление администратором не запрещается.

Приёмка: таких характеристик в БД нет; товары, brand/model и остальные
характеристики не изменились; тесты фильтра, одиночных и объединяемых товаров,
typecheck/lint/build проходят.
