## Подбор техники — 27.11.2026

- `description` остаётся лидом. Новые markdown-поля `descriptionTop` и
  `descriptionBottom` — до и после подбора техники; по 20 000 символов.
- `seoText` сохраняется как legacy: если оба новых поля пусты, выводится старый
  текст. Новые поля не дублируются со старым текстом.
- `Service.equipmentTypes` — many-to-many; удаление связи не удаляет вид.
  Админские GET/POST/PATCH возвращают `equipmentTypeIds`; POST/PATCH принимают
  уникальный массив существующих ID (до 100). Неизвестный ID → 400 по полю;
  отсутствующее поле PATCH сохраняет связи, `[]` очищает.
- Публичный GET `/api/services/{slug}` возвращает новые HTML-поля и `equipment`:
  опубликованные привязанные виды опубликованных разделов и все их опубликованные
  модели с фото/характеристиками, без `take`; порядок каталога.
- Между текстами земляных работ: чёрный блок, слева виды, справа выбранная модель,
  ниже все миниатюры выбранного вида. По умолчанию первый вид и первая модель;
  при смене вида выбор модели сбрасывается. Пустой вид: сообщение и CTA подбора;
  нет привязок: блок не выводится. Заказ открывает общий drawer с ID модели.
- Админка позволяет редактировать новые тексты и связи у каждой услуги.
  Новые связи не назначаются автоматически. Старые тексты не удаляются;
  земляные работы разделяются по смысловой границе перед разделом стоимости.
- Приёмка: схемы/DTO/формы/сервисный слой и переключение выбора покрыты Vitest;
  lint, typecheck, build, SSR и аудит 375/768/1280, переключения и drawer через CDP.
