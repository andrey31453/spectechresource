# Главная: карточки видов — 27.11.2026

Согласовано: удалить обзорный блок «От котлована до свай: 4 раздела каталога».
Четыре цветные секции категорий сохраняют заголовки, описания и темы из БД.
Вместо выбранной модели, фильтров и миниатюр — однорядная лента карточек видов
в оформлении карточек каталога: фото, название, количество моделей, цена «от»,
краткая информация. Карточка ведёт на существующую страницу вида.
По 2/3/4 карточки при ширине <768 / 768–1279 / ≥1280 px, независимая
пагинация стрелками и точками для каждой категории. При смене диапазона ширины
ленты возвращаются на первую страницу. Фото — `object-cover`, с обрезкой краёв
вместо пустот. Кнопки на границах отключены, текущая точка — `aria-current`.

Источник данных — опубликованные виды и модели `GET /api/home`.
Количество — число опубликованных моделей этого вида и категории (не физический
остаток машин). Цена — `EquipmentType.priceFrom` и `priceUnit`; если цена не
задана, минимум цен опубликованных моделей с той же единицей (час или смена).
Для погонных метров подстановка из моделей запрещена. Нет цены — «Цена по запросу».
Фото — обложка галереи вида, запасное — первое фото модели. Нет фото — текстовое
состояние. Краткая информация — `descriptionTop`, запасной источник —
`worksPerformed` («Какие работы выполняет»), без markdown-разметки, до трёх
строк. Нет описания — блок текста не выводится. Виды без моделей сохраняются.

Изменения только главной; каталоги категорий и страницы моделей не меняются.

и выбранных машин, корректные ссылки/цены/счётчики, проверки и аудит 375/768/1280.
