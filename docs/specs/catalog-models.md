# Каталог моделей и описания видов

Согласовано 24.11.2026. Крупные Category — группировка главной, не фильтр каталога.

- `/katalog`: слева опубликованные виды EquipmentType, справа все доступные модели опубликованных видов и разделов. На мобильном фильтр над карточками. Выбор вида фильтрует модели без перехода; «Вся техника» сбрасывает фильтр.
- `/arenda-{slug}` сохраняет адрес. Описания вида выводятся непосредственно перед списком моделей и после него; при пустом списке — сообщение об отсутствии моделей между описаниями.
- EquipmentType.descriptionTop — nullable Markdown до 20000 символов. Существующий seoText остаётся нижним описанием, без переноса данных. Оба поля доступны вне свёрнутого SEO-блока в AdminTypeFields.
- POST/PATCH видов принимают descriptionTop; trim, пустое значение → null, отсутствующее поле PATCH не изменяет данные. Авторизация и CSRF сохраняются. HTML экранируется существующим renderMarkdown.
- GET /api/catalog сохраняет прежний контракт для навигации. Новый GET /api/catalog/models возвращает виды с описаниями и полный список моделей без ограничения take; скрытые виды/разделы и недоступные модели исключены.
- Карточки ведут на существующие страницы моделей, показывают фото, название, описание, характеристики и цены. Пустые цены — «Цена по запросу».
- На десктопе (от 1024 px) список видов в каталоге — sticky с отступом 96 px под шапкой, собственной прокруткой и максимальной высотой `100dvh - 112px`. На мобильном — обычный поток над карточками.
- Страницы `/arenda-{slug}` используют тот же CatalogModelsGrid без бокового списка: от 1024 px — 3 колонки, от 1280 px — 4 вместо 3 в каталоге; до 1024 px сетки одинаковы.
- На странице вида модели идут сразу после верхнего описания и до условий. Галерея после моделей — горизонтальная лента миниатюр высотой 120 px (160 px от 640 px), без крупной обложки. Клик открывает фото целиком без обрезки в полноэкранном dialog: стрелки и клавиши ←/→ переключают фото по кругу; Escape, фон и кнопка закрывают просмотр. Пока просмотр открыт, прокрутка страницы заблокирована; закрытие восстанавливает прокрутку и фокус миниатюры. При одном фото стрелок нет, при пустой галерее блок скрыт. Галерея страницы товара не изменяется.

- Пустой список в общем CatalogModelsGrid — светло-красная плашка с декоративной красной иконкой 64/80 px и заголовком «Нет техники в списке? Поможем решить вашу задачу». Текст предлагает обсудить работы и возможные решения без гарантии наличия техники. Кнопка «Обсудить задачу» открывает существующую боковую форму через `#zayavka`, передавая вид техники со страницы или из выбранного фильтра. Сообщение имеет `role="status"`, кнопка находится вне live-region.
